Cookie Manager with Daily Quotes 隐私权政策

发布主体：七九在线科技 (79team) · 适用版本：v1.2.6+ · 扩展 ID: jbddngoogmpocbdmoengcehnobapodpf

七九在线科技（以下简称“我们”或“79team”）非常重视用户隐私与数据安全，并始终致力于保护您的个人数据。本隐私权政策旨在向您说明 Cookie Manager with Daily Quotes 浏览器扩展程序如何处理、使用和保护您的数据，以确保本扩展 100% 符合 Chrome Web Store 开发者政策与全球隐私保护准则。

一、我们收集与处理的数据

根据本扩展的功能定位，我们严格遵循最小化权限与数据本地化原则，绝大多数功能完全在本地浏览器沙箱中闭环运行：

1. Cookie 访问与管理 (cookies 权限)

  • 读取与修改：本扩展需要访问您当前访问站点的 Cookie 数据，用于为您提供 Cookie 检索、添加、编辑、删除、过期时间调整以及 SameSite/Secure/HttpOnly 属性配置功能。
  • 数据流向：所有 Cookie 读取与修改均直接在您的本地浏览器进程内完成。我们绝不会将您的任何 Cookie、Session ID、Token 或敏感登录凭证上传至任何远程服务器或第三方机构。

2. 本地偏好设置与固定列表 (chrome.storage.local)

  • 固定 Cookie (Pinned Cookies)：当您主动使用“固定 Cookie”功能时，该 Cookie 的键值和域名规则将被保存在浏览器的本地存储中，以便在新标签页或刷新时自动帮您应用。
  • 用户首选项：包括语言偏好（简体中文 / English）、日间/暗色主题状态、每日格言与天气缓存信息。
  • 本地存储目的：仅用于提升日常操作的便捷性，所有数据均保留在您的物理设备本地。

3. 当前活动标签页感知 (activeTab / tabs 权限)

  • 域名匹配与过滤：本扩展需要获取当前活动标签页的域名与 URL，以实现自动过滤并仅展示与当前网页相关的 Cookie 列表。
  • 数据处理：标签页信息仅在弹窗打开时临时在内存中读取，弹窗关闭即销毁，绝不持久化记录您的浏览历史。

4. 辅助服务请求 (天气与每日励志格言)

  • 天气与逆地理编码：为了在顶部信息面板展示您所在城市的实时天气与温度，本扩展会请求公开的气象服务 API。地理位置仅用于匹配就近城市天气，绝不记录、上传或追踪您的物理行踪轨迹。
  • 每日中英双语名言：为了给您的研发与调试工作提供正向情绪激励，本扩展会在本地或公开只读源获取每日精选格言，该请求为纯静态 GET 请求，不携带任何个人识别符。

二、数据用途与安全承诺

  • 完全本地沙箱运行：本扩展不具备任何收集用户数据的中央服务器。您导入、导出、编辑的任何 Cookie 明文数据，均存储于您自己的物理设备中。
  • 零广告与零行为追踪：本扩展不包含任何商业广告模块，不植入第三方行为分析探针，彻底尊重您的专注与隐私。
  • 无痕与隐私友好：支持在 Chrome 隐身模式（Incognito Mode）下受控运行，退出隐身模式后产生的临时会话数据将按浏览器原生机制自动销毁。

三、数据的共享与转让 (Data Sharing and Transfer)

我们郑重做出如下合规声明：

  • 绝不向任何第三方出售、转让、出租或共享您的任何 Cookie、个人数据或浏览信息。
  • 所有数据绝不用于个性化广告投放、用户画像挖掘或商业征信。
  • 所有存储数据受 Chrome Extension 原生沙箱隔离保护，除您当前浏览器中的本扩展外，任何第三方网页脚本均无法越权访问。

四、联系我们与开源反馈

如果您对本隐私权政策、数据安全或功能实现有任何疑问，请随时通过我们的公开分发中心进行反馈：

  • 官方代码与反馈渠道：GitHub Issues
  • 官方主仓：rowkin/browser-plugins/cookie-manager
  • 打造团队：79team

79team ("we", "us", or "our") values user privacy and data security. This Privacy Policy describes how the Cookie Manager with Daily Quotes browser extension collects, uses, and safeguards your data, ensuring 100% compliance with Google Chrome Web Store Developer Policies and global privacy standards.

1. Information We Collect and Process

We strictly adhere to the principle of data minimization and local sandboxing:

1.1 Cookie Manipulation (cookies permission)

  • Read & Write: Used solely for inspecting, creating, editing, and deleting cookies on the current domain as explicitly directed by you.
  • Data Flow: All cookie operations are executed strictly within your local browser process. We NEVER transmit session IDs, auth tokens, or cookie credentials to any remote server.

1.2 Local Preferences (chrome.storage.local)

  • Pinned Cookies: Saved locally in your browser storage so they can be automatically applied across tabs or upon refreshes.
  • User Preferences: Theme preference, language setting, and cached weather/quote metadata.

1.3 Active Tab Context (activeTab / tabs permissions)

  • Used only when the popup is open to match and filter cookies related to the current website domain. Never logs or tracks your browsing history.

1.4 Live Weather & Daily Quotes

  • Weather: Queries public weather APIs with reverse-geocoded coordinates solely for displaying local temperature. Never records or uploads your location trajectory.
  • Daily Quotes: Fetches inspirational quotes via read-only GET requests without any tracking identifiers.

2. Security & Zero-Tracking Guarantee

  • 100% Local Sandbox: No central server collects user telemetry or browsing behavior.
  • Zero Commercial Tracking: No ads, no analytics trackers, no fingerprinting scripts.
  • Incognito Respect: Seamlessly operates in private windows while isolating session traces.

3. Data Sharing and Transfer

  • We will NEVER sell, rent, or transfer your cookies or personal data to any third parties.
  • Data is never leveraged for targeted advertising, credit assessment, or profiling.

4. Contact & Community Support

If you have any questions regarding this Privacy Policy, please reach out via:
